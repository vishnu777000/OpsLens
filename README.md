# OpsLens

AI-powered DevOps Observability Platform

## Mission

OpsLens helps developers and DevOps teams monitor infrastructure, analyze logs, detect failures, and identify root causes using AI.

---

## Features

- Authentication
- Centralized Logging
- Monitoring
- AI Root Cause Analysis
- Incident Timeline
- Kubernetes Support
- Docker Integration
- Alerts
- Dashboard
- CI/CD
